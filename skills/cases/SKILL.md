# cases — the case store index

The stage-one index of the case store: settled point decisions, one entry per
adjudicated question (`corpus/decisions/`, a ledger — see
[/corpus/decisions/README.md](/corpus/decisions/README.md)). Each case states a
constraint on future forks and the facts that would falsify it.

## The three-stage read

1. **Skill name and description** — always visible; the legible key that routes
   a planning session to open this skill.
2. **This index** — one line per case: id, status, and the one-line summary. The
   region below is generated from the entries by `tools/index-gen`; edit the
   cases in `corpus/decisions/`, never this region.
3. **The case record** — `corpus/decisions/D-nnnn.md`, opened when a summary
   matches the work in hand.

## Read protocol

The hook is the summary line itself: a case carries no routed `fires-when`, so
the full scan is the router — cheap summaries make scanning the whole index the
way a case is found.

The summaries are written in the tenant's grown work-shape vocabulary — the terms
the tenant names for the work shapes that recur (see
[/corpus/vocabulary/README.md](/corpus/vocabulary/README.md)). A summary matches
when the work in hand carries the shape it names.

**Do:** ground the shape of the work in hand in the shared vocabulary before
scanning the summaries.
**Don't:** don't match a summary on surface words alone — a shape named in the
vocabulary is the join key, and an ad-hoc paraphrase slides past the match.

**Do:** scan every summary at plan time and open the record behind any summary
that matches the work in hand.
**Don't:** don't comply from a summary alone — a summary routes to the case and
never substitutes for it; acting on it without opening the record is acting
without the warrant.

**Do:** follow a `superseded → D-nnnn` pointer to the successor and comply from
that record.
**Don't:** don't skip a `superseded` or `moot` entry a pointer led you to — a
retired case stays listed precisely so its successor can be reached.

**Do:** comply from the record you opened.
**Don't:** don't obey an index cell — the cell carries activation and lifecycle
fields only, under the settlement test in
[/corpus/LANGUAGE.md](/corpus/LANGUAGE.md); the constraint lives in the record.
