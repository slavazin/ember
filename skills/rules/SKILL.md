# rules — the rule store index

The stage-one index of the rule store: recurring conditional duties, one
register entry per rule (`corpus/rules/`, a register — see
[/corpus/rules/README.md](/corpus/rules/README.md)). Each rule routes to a
session by work shape and carries the duty its warrant supports.

## The three-stage read

1. **Skill name and description** — always visible; the legible key that routes
   a planning session to open this skill.
2. **This index** — one line per rule, leading with the disclosed residue, then
   the hook (`fires-when`), the exclusion (`not-this`), the floor, and the
   status. The duty sentence is never here. The region below is generated by
   `tools/index-gen`; edit the rules in `corpus/rules/`, never this region.
3. **The rule record** — `corpus/rules/R-nnnn.md`, opened when a rule's
   `fires-when` matches the work in hand.

## Read protocol

The hook is `fires-when` — the work shape that routes a rule to a session; the
`not-this` field is the exclusion that keeps it from binding shapes it must not.
The residue leads the line so a reader sees the gap before reaching for the duty.

`fires-when` and `not-this` are written in the tenant's grown work-shape
vocabulary — the terms the tenant names for the work shapes that recur (see
[/corpus/vocabulary/README.md](/corpus/vocabulary/README.md)). A rule fires when
the work in hand carries one of those shapes.

**Do:** ground the shape of the work in hand in the shared vocabulary before
scanning `fires-when`.
**Don't:** don't match `fires-when` on surface words alone — a shape named in the
vocabulary is the join key, and an ad-hoc paraphrase slides past the fire.

**Do:** apply a rule whose `fires-when` matches the shape of the work in hand.
**Don't:** don't fire a rule whose `not-this` names the shape you hold — a
matched exclusion is the router telling you the duty does not bind here.

**Do:** open the record to read the duty, then follow its warrant to the cited
decisions.
**Don't:** don't comply from the index line — its residue and hook route and
disclose; a duty obeyed from the cell is obeyed without its warrant.

**Do:** apply only a rule at status `active`.
**Don't:** don't fire a `demoted` rule — it stays listed as the record of a duty
once carried, not a duty to discharge.

**Do:** read the residue as the standing gap — what the rule, fully enforced,
still does not check.
**Don't:** don't read the residue as reassurance; it discloses a gap, and acting
as though the gap were closed is the failure it warns of.
