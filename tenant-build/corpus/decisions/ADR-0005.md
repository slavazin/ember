# The constitution is a skill loaded by a boot obligation; the agent spec carries only the boot protocol

## Context
A boot obligation in the saved agent's instructions — load the constitution before any
planning — is equivalent in essence to always-loaded. That falsifies ADR-0004's warrant for
a bespoke projection, so the spec-block mode, the drift check, and a constitutional store
directory are all unnecessary.

## Options considered
### Option A — keep the generated agent-spec block
Shape: ADR-0004. Verdict: rejected — its warrant fails once an obligation suffices.
### Option B — the constitution as a skill, loaded by obligation
Shape: the agent instructions carry a few lines of boot protocol; the constitution rides the
three-stage attention like any store. Verdict: chosen.

## Decision
The constitution is a skill in the three-stage attention; the saved agent's instructions
carry only a boot obligation to load it, and the `session` skill, before any planning. No
generated agent-spec block, no spec-versus-source drift check, no constitutional store directory.

## Consequences
The constitution reads through the same mechanism as every store. Forecloses a bespoke
always-loaded mechanism, and moves the guarantee from a mechanism to an obligation.

## Warrant
- The shipped skill states its boot-obligation loading (as of 2026-08-28,
  skills/constitution/SKILL.md); the `session` skill loads it first at boot
  (skills/session/SKILL.md).
- False if: a session is observed proceeding past boot without the constitution loaded —
  the boot obligation proving skippable reopens the projection question.
