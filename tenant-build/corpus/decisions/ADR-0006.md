# Git history and the merged pull request are the trace; no jot pile, session log, or trace store

## Context
The corpus keeps a register/ledger distinction and a permanent-write gate that runs through
pull requests. A separate jot pile and session-log store would duplicate what commits and
merged pull requests already record, and a history amended outside git stops being evidence.

## Options considered
### Option A — a jot pile plus a session-log/trace store
Shape: hand-written observation and event stores beside the corpus. Verdict: rejected — a
hand-maintained copy of derivable history only drifts.
### Option B — git history as the trace
Shape: dispositions and drafts ride the pull request; the pre-admission tier is un-merged
branches. Verdict: chosen.

## Decision
The event trace is git history plus the merged pull request; the corpus keeps no jot pile,
session log, or trace store. Candidate drafts live on un-merged branches until a merge
admits them.

## Consequences
Removes hand-maintained history that duplicates git and makes the merged pull request the
session's record. Forecloses reconstructing session events from anything but commits and
merged pull requests.

## Warrant
- The close-out records dispositions into the pull request, not a log (as of 2026-08-28,
  skills/session/SKILL.md); the corpus declares no trace store (corpus/README.md).
- False if: a required record has no sink in git history or a merged pull request.
