# A corpus write leaves the sandbox as a patch the host pulls back; the scoped push token never enters the sandbox

## Context
The permanent-write gate files a candidate through a push and a pull-request merge (ADR-0007).
The agent that produces a corpus entry runs inside a provisioned sandbox. Where the push
originates decides where the scoped push token must live: a push started inside the sandbox
requires the token to reach the sandbox, and a token placed there is readable by every tool
the agent runs in that workspace. The sandbox has outbound HTTPS to GitHub and git present, so
it can build a commit and emit a patch; it cannot be handed a credential cleanly.

## Options considered
### Option A — push the branch from inside the sandbox
Shape: inject the scoped token into the sandbox and `git push` the candidate branch from the
agent's workspace. Verdict: rejected — no clean injection path exists, and a token in the
workspace is exposed to every tool the agent runs there.
### Option B — emit a patch, push from the host
Shape: the agent writes the entry to a workspace file; the diff is retrieved through the
harness file-download API as a patch; a host-held helper applies it in an isolated worktree
off `origin/main` and opens the pull request with the host-held token. Verdict: chosen — the
token stays on the host and the sandbox never authenticates outward.

## Decision
A corpus write produced inside a sandbox leaves it as a patch retrieved through the harness
file-download API; a host-held helper applies the patch in an isolated worktree off
`origin/main` and opens the pull request. The scoped push token is held on the host and never
enters the sandbox. The push-then-merge gate of ADR-0007 is unchanged — only the push's origin
is fixed to the host.

## Consequences
Holds the push token's blast radius to the host, off the agent's tool surface. Makes the
patch-emit and pull-request-open step the human-gated boundary. Forecloses an in-sandbox push
as the write path while no credential reaches the sandbox; a remediation that needs to
authenticate outward routes through the host helper instead of pushing itself.

## Warrant
- The harness exposes no sandbox secret or environment-variable injection; the sandbox has
  outbound HTTPS to GitHub and git present, so it emits a patch but cannot authenticate a push
  (as of 2026-08-28, TrueForge v0.1.4).
- The two-tier push-and-merge gate this refines is ADR-0007.
- False if: a harness release injects a scoped secret into the sandbox such that an in-sandbox
  push authenticates without the credential becoming readable to the agent's other tools.
