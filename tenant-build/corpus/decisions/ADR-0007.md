# The permanent-write gate is two-tier: approval on the push, the pull-request merge as the adjudicating write

## Context
The harness approval pauses a tool call for human confirmation, but it gates the call, not
the durable content, and leaves no adjudication record. A single approval cannot be both the
in-session gate the criterion rewards and the durable, evidenced write.

## Options considered
### Option A — the in-session approval alone is the gate
Shape: an approved push is the permanent write. Verdict: rejected — no adjudication record,
no durable evidence.
### Option B — a two-tier gate
Shape: the approval gates the push; the merge is the durable write. Verdict: chosen.

## Decision
No agent writes to a permanent store. An agent files candidates on a branch; the in-session
approval gates the push, and the pull-request merge is the durable, adjudicating write that
admits the entry and mints its id.

## Consequences
Makes the merge the single admitting event and the pull request its evidence, which doubles
as the review trail. Forecloses an agent committing to a store.

## Warrant
- The proposal procedure files candidates through a branch and pull request (as of
  2026-08-28, skills/corpus-write/SKILL.md).
- False if: a durable store gains an entry without a human merge.
