# The close-out is its own skill, run from fresh context, distinct from the boot skill

## Context
The fast loop has two halves: a boot that orients a session from the corpus, and a
close-out that judges the session's work — dispositions, retro, candidates — back
into it. A prior roster consolidation folded both into one `session` skill, an
optimization of skill count. That consolidation never weighed close quality: run in
the implementing turn, from the boot skill, the close-out carries the implementer's
own context into the judgment it is supposed to make of that work, and it loads the
boot's planning instructions it does not need.

## Options considered
### Option A — one `session` skill covering boot and close
Shape: a single fast-loop skill; the close-out is a section of it, run in the
implementing turn. Verdict: rejected — the judgment of a session's work inherits the
context that produced the work, and the boot's planning instructions load with it.
### Option B — boot and close as two skills, the close loaded from fresh context
Shape: `session` boots; `close` runs after implementation from a fresh read of the
branch and pull request. Verdict: chosen — the close judges the work without the
implementer's context, and loads only its own protocol.

## Decision
The close-out is the `close` skill, distinct from the boot-half `session` skill, and
loaded from fresh context after implementation. `session` orients at start and walks
the planning latches; `close` records dispositions, walks the retro lenses, files
candidates, and walks the closing latches. The agent's close obligation loads
`close`; `close` re-derives its inputs from the branch and the pull request, so an
agent holding none of the implementation context runs it in full.

## Consequences
Enables a close-out that judges the work without the implementer's context. Forecloses
reading the close procedure from the boot skill, and forecloses a close-out that must
run in the implementing turn.

## Warrant
- The close protocol lives in `skills/close/SKILL.md`; the boot half is
  `skills/session/SKILL.md` (as of 2026-08-28).
- Constitution Article 4 names both skills as the procedure (skills/constitution/SKILL.md).
- The agent's close obligation loads `close` from fresh context
  (tenant-incident/agent/instructions.md).
- False if: the fast loop's close is folded back into a single skill, or the close-out
  is required to run in the implementing turn rather than from fresh context.
