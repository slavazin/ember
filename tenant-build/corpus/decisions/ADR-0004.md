# The constitution is projected into the saved agent spec as a generated, gated block

## Context
Skills load on demand, not always-on, so the constitution's always-loaded character needs a
mechanism. The first answer projects the constitution into the saved agent's instructions
as a generated block, with a spec-block projection mode and a spec-versus-source drift check.

## Options considered
### Option A — a generated constitution block in the agent spec
Shape: index-gen emits the block; a check guards spec-source drift. Verdict: chosen here.
### Option B — the constitution as an ordinary skill, loaded by obligation
Shape: an instruction to load it before planning. Verdict: deferred pending whether an
obligation is equivalent to always-loaded.

## Decision
The constitution is always-on by projection into the saved agent's instructions as a
generated, gated block, regenerated and drift-checked against its source.

## Consequences
Guarantees the constitution loads without a boot step. Forecloses reading the constitution
through the same mechanism as every other store, and adds a projection mode and a drift
check to maintain.

## Warrant
- False if: a boot obligation in the agent instructions is equivalent in essence to
  always-loaded, making the projection and its drift check redundant.
